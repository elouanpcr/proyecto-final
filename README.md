EcoBot 
Autor: Elouan Dubois Hormazábal

La finalidad del proyecto es ayudar a las personas a clasificar los residuos.
Esto se puede hacer a través de de una clasificadora, una guía de clasificación. 
Además tiene una parte divertida, un quiz, a si el usuario puede divertirse mientras aprende. 
La clasificadora tiene historial, facilitando la búsqueda reiterada de los residuos. Los clasifica a través de tarjetas de presentación. También puedes pedir más información, como el tiempo de descomposición.
La guía está dividida en tarjetas de colores, cada tarjeta tiene sus respectivas subcategorias.
Y por último el quiz, este es un cuestionario dinámico, eso significa que cada vez que se accede a él van cambiando las preguntas, te pide que marques la casilla del color que va cada residuo. 
Para utilizar la web hay que abrirla y te van a ir saliendo las distintas paginas.
Mi proyecto es muy importante, con él las personas pueden ir aprendiendo como catalogar y clasificar residuos, minimizando el cambio climático. 
Las personas pueden ir utilizando el sitio web en su vida diaria.
